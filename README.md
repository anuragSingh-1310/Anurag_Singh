# Anurag Singh — Portfolio Website

A modern, high-performance personal portfolio website built with React, TypeScript, Vite, Tailwind CSS, Motion, and Lenis Smooth Scroll.

## 🚀 Features
- **Smooth Scrolling**: Powered by [Lenis](https://github.com/darkroomengineering/lenis) for silky smooth scrolling animations.
- **Micro-interactions & FX**: Three.js dot fields, click sparks, fluid blur shaders, and animated spring reveals.
- **Interactive Demos**: Live simulation widgets (VaidyaSetu diagnostic AI classifier, Food & Nutrition Cart sync).
- **Responsive & Accessible**: Fully responsive across mobile, tablet, and ultra-wide displays with Dark/Light theme switching.
- **Sleep Screen / Zen Mode**: Ambient screensaver mode after inactivity.

## 🛠️ Tech Stack
- **Framework**: React 19, Vite, TypeScript
- **Styling**: Tailwind CSS v4, Vanilla CSS variables
- **Motion & 3D**: Motion (Framer Motion), Three.js
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React

## 💻 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone repository
git clone https://github.com/anuragSingh-1310/Anurag_Singh.git

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
npm run build
```
